# 学案挖空补全

适合学案中有明确留空、公式空格或待填写表格，希望根据讲义上下文和指定参考资料补全的情况。仅 Plus、Pro、Max 提供补全 Skill；请先按[档位与入口对照表](README.md#档位与入口)选择一档。PPTX 输出仅 Pro/Max 支持。

```text
请使用 [Plus / Pro / Max] 档的 `[入口 Skill 名称]` Skill 处理附件《[文件名]》，并启用学案智能补全。输出为[HTML / DOCX / Markdown / PPTX；PPTX 仅 Pro/Max]。

请先通读整份学案和我提供的参考资料，再补全学案里明确留出的空格；保留原有已填写内容、结构、符号和版式。数理证明请跨页查找学案已提及的定义、定理、公式、变量范围和假设，逐步检查推理及定理适用条件，避免循环论证。

每个补全都要能指出依据。若学案和参考资料不足以确认答案，不要猜测或擅自扩写，请保留空格并标记“待老师确认”。如确需外部查询，只查询缺失的具体知识点，并在答案附近注明来源。

正文布局为[仅译文 / 中外文对照 / 术语首次出现时标注原文]；其他要求：[填写或删除]。
```

使用 Plus 时，将 `[入口 Skill 名称]` 填为 `foreign-academic-translator-plus`；Pro 和 Max 使用 `translation-orchestrator`。Plus、Pro、Max 的入口会调用各自套件中的学案补全 Skill，并由独立质量审计检查依据和最终成品。
